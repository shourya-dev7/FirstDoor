# 🏥 FirstDoor

FirstDoor is a healthcare decision-support prototype designed for early health risk assessment and appropriate clinical routing.

The system collects user health information and provides:

- Symptom-based risk assessment
- Emergency safety detection
- Specialty routing
- Psychological screening support
- Laboratory analysis
- Imaging analysis
- Hospital referral support
- AI-generated medical explanations
- A structured assessment roadmap

> ⚠️ **Disclaimer:** FirstDoor is an educational and prototype clinical decision-support system. It does not provide a medical diagnosis and is not a substitute for professional medical advice or emergency services.
